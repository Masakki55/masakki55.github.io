要約 (TL;DR)

  • 当アプリ運営者 (Masaki) は個人情報を一切収集しません。
  • 学習機能 (問題演習・解説・統計・復習) はすべて端末内で完結、 通信不要です。
  • 無料版は AdMob 広告 を表示するため、 Google AdMob SDK が以下を Google に収集・共有 します:
    • 広告 ID (Advertising ID)
    • IP アドレス
    • ユーザーインタラクション (広告閲覧・タップ等の broad event signals)
  • Pro 版 (¥980 買い切り) は AdMob SDK 自体を含みません ⇒ 完全オフライン動作、 第三者データ送信ゼロ。
  • 学習進捗・お気に入り問題・設定は あなたの端末内のみ に SQLite 保存。

1. 運営者

乙4 学習ラボ (「当アプリ」 「私たち」) は、 シンガポール在住の個人開発者 Masaki が提供する Android アプリです。 ブランド名: Masaki Made in Japan (Android publisher: com.masakimadeinjapan.*)。 Google Play Store で配信しています。

プライバシー関連・データ削除依頼・その他お問い合わせ: mk.madeinjapan@gmail.com (1-3 営業日以内に返信)

2. 当アプリ運営者 (Masaki) が収集 しない データ

明示的に、 当アプリ運営者は 以下を収集・送信しません:

  • 氏名・メールアドレス・電話番号・住所・生年月日
  • 使用状況分析 (Google Analytics・Firebase Analytics・Crashlytics は使用しません)
  • クラッシュレポート
  • 位置情報
  • 写真・連絡先・ファイル等の端末コンテンツ
  • 音声・センサーデータ
★ 重要な区別: 上記は 「当アプリ運営者 Masaki が収集しない」 リストです。 ただし無料版では AdMob (Google) が SDK 経由で広告 ID / IP / ユーザーインタラクション を独自に収集・共有します (§4.1 参照)。 これらは Google による収集であり Masaki の手元にはデータは届きませんが、 Google Play Data Safety 上は「収集 + 共有」 として申告しています。

3. 端末内のみに保存されるデータ

以下は あなたの端末内 (アプリ専用 SQLite データベース) にのみ保存され、 端末外に送信されません:

  • 学習進捗: 各問題の正答 / 誤答履歴、 正答率、 直近 7 日推移
  • お気に入り問題: 復習用にマークした問題 ID
  • 復習キュー: spaced repetition で次に出題する問題リスト
  • 設定: ダークモード / 通知設定 / Pro 版購入状態 / 広告除去 IAP 購入状態

アプリのアンインストール または アプリ設定 → ストレージ → データ消去 で全データが削除されます。

4. 第三者サービス

4.1 Google AdMob (★ 無料版のみ)

無料版 (com.masakimadeinjapan.otsu4) ではバナー広告 + 演習画面遷移時のインタースティシャル広告を表示します。 広告配信は Google AdMob が行います。 Google Mobile Ads SDK は以下 4 カテゴリのデータを SDK 動作時に自動的に Google に収集・共有します (Google 公式 Mobile Ads SDK Play disclosure ガイダンス準拠):

データ種別収集者用途Google Play Data Safety 申告
広告 ID (Advertising ID) Google (AdMob SDK 経由) 広告のフリーケンシー制御 / 関連性最適化 収集 + 共有
IP アドレス Google (AdMob SDK 経由) 地域別広告配信 / 不正クリック検出 収集 + 共有
ユーザーインタラクション Google (AdMob SDK 経由) 広告閲覧・タップの broad event signals (個人特定なし) 収集 + 共有
診断データ (Crashes / Performance) Google (AdMob SDK 経由) SDK クラッシュ報告・パフォーマンス計測 (Google ポリシー上 自動収集) 収集 + 共有 (automatic、 Google Mobile Ads SDK Play disclosure 公式準拠)

これらは Google による収集であり、 Masaki (当アプリ運営者) の手元にはデータは届きません。 ただし Google Play Data Safety 上は「収集 + 共有」 として正直に申告しています。 Google のプライバシーポリシーが適用されます:

  • Google プライバシーポリシー
  • Google 広告ポリシー
  • Google Play 広告 ID ポリシー

AdMob によるデータ収集・共有を完全に停止したい場合の選択肢:

  • Pro 版 (¥980 買い切り、 別パッケージ com.masakimadeinjapan.otsu4.pro) — AdMob SDK 自体を含まないため、 上記 4 カテゴリすべてが一切収集・共有されません。 ★ 完全停止を希望する場合は Pro 版を推奨します。
  • 広告除去 IAP (¥500 買い切り、 無料版から購入) — 広告表示は停止しますが、 AdMob SDK 自体はアプリに残存します。 SDK 初期化処理 (アプリ起動時の SDK ロード) で診断データ等が Google に送信される可能性があります。 SDK レベルでのデータ送信を完全停止したい場合は Pro 版をご利用ください。
  • Android Settings → Google → 広告 ID をリセット / Opt out of Ads Personalization を有効化 で、 広告 ID をリセット・パーソナライズ停止可能 (Google アカウント設定)。 ただし IP / インタラクション / 診断 の送信は SDK が動作する以上停止できません — 完全停止には Pro 版が必要です。

4.2 Google Play 課金 (Premium 購入時)

Pro 版 (¥980) または広告除去 IAP (¥500) の購入時、 取引は Google Play 課金システム (Google が直接運営) で処理されます。 支払いデータは Google が直接収集・処理し、 当アプリ運営者 (Masaki) は支払い方法・カード番号・請求先住所・氏名・その他の個人情報を一切受け取りません。 当アプリが Google から受け取るのは購入成功 / 失敗のバイナリ信号のみです。

Google Play 課金のプライバシーポリシーが取引に適用されます: Google プライバシーポリシー

5. 児童のプライバシー

当アプリは一般向けレーティングで、 児童を対象としていません。 Masaki としては個人情報を一切収集しないため、 米国 COPPA、 EU GDPR-K、 シンガポール PDPA 児童保護コード (2023)、 日本 個人情報保護法 児童データ取扱 (改正法 17 条) で求められる「児童データ取扱の同意取得」 等の主要義務は、 Masaki が運営する範囲では発生しません。 ただし、 無料版で Google AdMob を通じて Google が広告 ID / IP アドレス を取扱う部分については Google が独立した個人情報取扱事業者として各法令義務を負います (詳細は Google プライバシーポリシー)。 「準拠」 という表現は Masaki 個人による直接の法令遵守宣言 ではなく、 個人情報を収集しない設計上、 これら法令の児童データ取扱義務に該当する処理が発生しない事実を示すものです。

ただし無料版の AdMob は Google ポリシーに従い、 13 歳未満と判明したユーザーには適切な広告制御 (pers​onalized ads 無効化等) が Google 側で適用されます。 児童の保護者の方は、 完全に第三者データ送信のないPro 版 (¥980) のご利用を推奨します。

6. データ保持

Masaki が保持する個人データはありません (Google AdMob / Google Play 課金が処理するデータは Google が保持、 Google のポリシーに従う)。 端末内のローカルデータ (学習進捗・設定) は、 アプリのアンインストール または アプリ設定 → ストレージ → データ消去 まで保持されます。

7. あなたの権利 (地域別適用)

7.1 日本 (改正個人情報保護法 / APPI)

Masaki としては個人情報を収集しないため、 個人情報保護法 (改正法含む) の主要規定 (利用目的の特定・第三者提供制限・開示請求への対応等) は、 Masaki が運営する範囲では 適用されません。 ただし、 無料版 AdMob 経由で Google が収集する広告 ID 等については、 Google が個人情報取扱事業者として APPI 義務を負います。 詳細は Google プライバシーポリシー を参照ください。

Masaki への問い合わせ: mk.madeinjapan@gmail.com

7.2 EU / EEA / UK (GDPR / UK GDPR)

GDPR の下、 アクセス・修正・削除・データポータビリティの権利があります。 Masaki としては個人データを収集しないため、 Masaki から提供・削除できるデータはありません。 端末内データはアプリ設定 → ストレージ → データ消去 で削除可能。 Google が AdMob 経由で収集するデータについては Google に対し権利行使を行ってください。

7.3 米国カリフォルニア州 (CCPA / CPRA)

Masaki としては個人情報を販売・共有しません (収集自体しません)。 Google AdMob 経由のデータ取扱は Google のポリシーに従います。

7.4 シンガポール (PDPA 2012、 2020 改正)

シンガポール個人情報保護法 (PDPA) における Notification / Consent / Access/Correction の義務は、 Masaki としては個人データを収集しないため、 当アプリの利用自体からは発生しません (「PDPA に準拠している」 という表現は Masaki 個人による直接の法令遵守宣言ではなく、 個人データを収集しない設計上、 これら義務に該当する処理が発生しない事実を示すものです)。 無料版 Google AdMob 経由で Google が処理するデータについては Google が独立した事業者として PDPA 義務を負います。 お問い合わせ: mk.madeinjapan@gmail.com

8. ポリシー変更

本ポリシーを変更する場合 (例: 解析サービス追加、 サブスク追加、 SDK 入れ替え等)、 ページ上部の「最終更新」 日を更新し、 Google Play のリリースノートで明示し、 重大な変更については次回起動時にアプリ内通知を表示します。 本ポリシーは利用中のバージョンに適用されます (旧バージョンは GitHub repository の git history で archive されています)。

9. AI による解説生成について

当アプリの問題解説・引っかけ警告は、 Claude AI (Anthropic) で起草した後、 Codex CLI (OpenAI) による法令一次ソース突合監査を通過させたものです。 全ての法令引用・化学性質数値は、 e-Gov 法令検索・消防庁公式・規格省令 等の一次ソースを突合済です。 出典は問題ごとに「出典 タブ」 でご確認いただけます。 「鉄板」 「絶対出る」 等の一次ソース突合なき確信表現は禁止しています。

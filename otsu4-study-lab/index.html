📌 競合 7 アプリ調査の結果、 どこも対応してなかった 3 つ

  1. 「1 問差で落とす」 対策に特化 — 引っかけ問題に「合否分岐ポイント」 マーク。 似た用語 (第一石油類 vs アルコール類 / 棒状 vs 霧状) の混同ゾーンを徹底警告。
  2. 解説に政令番号 + 条文を明示 — 「政令第 306 号 別表第三より」 と一次ソースを表示。 e-Gov 法令検索で あなた自身が verify 可能。 二次ソース (講座サイト / YouTube) 依拠の解説はゼロ。
  3. 誇大広告ゼロ宣言 — 「絶対合格」 「裏技」 「100% 出る」 等の表現は使いません。 試験対策に必要なのは、 1 問差を埋めるための「ひっかけ警告 + 法令数値暗記 + 過去問演習」 のみです。

引っかけポイント例

★ 例 1: 第一石油類 vs アルコール類 アセトン (CH₃COCH₃) は炭素数 3 の有機溶剤、 一見アルコール類のように見えるが 第一石油類 (引火点 -20℃、 指定数量 200L)。 アルコール類の定義 = 「炭素数 1-3 の 飽和一価アルコール」 で、 アセトンはケトンなので該当しない。
出典: 政令第 306 号 別表第三
★ 例 2: 棒状放射 vs 霧状放射 (強化液) 強化液の油火災 (B 火災) 適応は 霧状放射のみ。 棒状放射では油火災に適応しない。 ★ 試験で 1 問差で落ちる人多数。
出典: 消火器の技術上の規格を定める省令 (昭和 50 年 自治省令第 26 号)

📢 AdMob (無料版広告) について
無料版では Google AdMob のバナー広告 + インタースティシャル広告を表示します。 Google Mobile Ads SDK は以下 4 カテゴリのデータを SDK 動作時に自動的に Google に収集・共有します (Google 公式 SDK ガイダンス準拠):
  • デバイス識別子 (Advertising ID)
  • IP アドレス
  • ユーザーインタラクション (広告閲覧・タップの broad event signals)
  • 診断データ (Crashes / Performance、 SDK 自動収集)
これは Google Play Data Safety 申告通り (「収集」 + 「共有」) です。 詳細は privacy §4.1 で。

4 カテゴリすべてを完全停止したい場合は Pro 版 ¥980 をご利用ください (AdMob SDK 自体を含まないため、 SDK 動作も発生しません)。 広告除去 IAP (¥500) では広告表示は停止しますが、 SDK 自体は残存するため診断データ等は SDK 動作時に Google に送信される可能性があります — 完全停止には Pro 版を推奨します。

よくある質問

Q1. 無料で全問題使えますか?

はい、 500 問すべて + 解説 + 統計 + 復習モードまで無料版でフル利用可能です。 違いは AdMob 広告の表示のみです。 「無料 N 問まで」 のような制限はありません。

Q2. オフラインで使えますか?

問題演習・解説・統計・復習などの学習機能はすべて端末内で完結し、 通信不要です。 ただし無料版は AdMob 広告配信のため通信が発生します。 Pro 版 (¥980 買い切り) は AdMob SDK を含まないため完全オフラインで動作します。

Q3. 問題は最新の試験範囲に対応していますか?

2026 年 5 月時点の出題範囲 (改正消防法 + 政令第 306 号現行版) に対応しています。 法改正があった場合は次回バージョン update で反映 (アプリ内 release note でお知らせ)。 「最終更新日」 はアプリ Setting 画面で確認できます。

Q4. アカウント登録は必要ですか?

不要です。 個人情報の入力は一切ありません。 学習進捗は端末内に保存され、 アプリのアンインストールで完全に削除されます (詳細: プライバシーポリシー)。

Q5. なぜ「合格率」 や「使用者の声」 を載せないんですか?

合格はアプリ単体ではなく受験生本人の努力で達成されるものだからです。 「このアプリで合格率 90%」 のような誇大広告ゼロ宣言を運営方針としています。 アプリは学習補助具として正直に位置付け、 効果は使ってから判断してください。
